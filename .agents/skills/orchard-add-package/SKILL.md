# Orchard: add package

Create a new **`home/dot_config/exact_orchard/exact_apps/<app_id>.fish`** package so `orchard list` / `orchard install` can manage the app.

- Use the `orchard` skill and its applicable references for workflow, format, checklists, and conventions.
- Use the user’s message (app name, `app_id`, URL, cask, GitHub repo, etc.) as input.
