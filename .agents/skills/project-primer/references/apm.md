# APM

Read this before editing APM source files under `home/dot_apm/` or APM Fish helpers and commands:

- `home/dot_config/fish/conf.d/99-apm.fish`
- `home/dot_config/fish/functions/apm-add-skill.fish`
- `home/dot_config/fish/functions/apm-update.fish`

When editing those Fish files, also read [fish](fish.md).

## Source Files

- Treat `home/dot_apm/apm.base.yml` as the tracked source shared by both environments.
- Treat `apm.external.yml` and `apm.internal.yml` in that directory as tracked environment sources. External is the company environment; internal is the home environment with private Omico Skills and a separately installed Vita plugin.
- Select the machine environment with the ignored `apm.environment` source file containing `external` or `internal`. A saved selection takes precedence. On first use, query the github.com account through `gh`: `Omico` selects internal, another account selects external. If `gh` is unavailable or the query fails, prompt for a manual selection; without terminal input, return an error. Save successful selections. Shell startup does not query or prompt.
- Keep `apm.custom.yml` as the existing local, ignored customization source shared by both environment selections. Preserve custom entries when switching environments.
- Treat `~/.apm/apm.yml` as the merged runtime config generated from the base, selected environment, and custom sources.
- Treat `~/.config/fish/conf.d/apm.fish` as generated by the APM installer; ignore it in `home/.chezmoiignore.tmpl` so apply cleanup does not remove it.
- Run `__apm-merge-source-config` (via `apm-update` or `apm-add-skill`) after changing source files so `~/.apm/apm.yml` stays in sync.
- Use `apm-add-skill <package>` for local custom dependencies and `apm-add-skill --global <package>` for tracked base dependencies.
- `apm-add-skill` finishes with `chezmoi add` on `~/.apm/apm.custom.yml` or `~/.apm/apm.base.yml`, depending on whether `--global` was used.

## Migration

- When changing a machine's environment, check custom dependencies, the APM removal plan, and Vita availability. Configuration merging does not reconcile installed packages or separately managed plugins.

## Dependencies

- Omit the `github.com/` prefix for GitHub dependencies; use `owner/repo/path` instead.
- Keep every entry under `dependencies: apm:` sorted.
- Compare entries by the full dependency string exactly as written.
- Preserve the existing YAML structure and quoting style.
